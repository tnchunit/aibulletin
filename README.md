# 臺南市教育公告 OCR 自動下載與歸檔助手 (Tainan Edu Bulletin Assistant)

專為學校行政、資訊組長及教師打造的工作網頁工具。支援公文簽收聯截圖貼上即辨識、公告附件自動下載歸檔、以及移動辦公支援！

---

## 🌟 核心模式與功能

### 1. 💻 本機 Windows 整合模式 (`localhost:8088`)
- 雙擊執行 `啟動公告下載器.bat` 即可啟動。
- **Windows 原生 WinRT 繁中 OCR 引擎**：極速辨識。
- **自動建夾歸檔**：以 `[公告編號] 公告標題` 自動建立本機資料夾，下載所有附件與文字檔。
- **一鍵開啟檔案總管**：在網頁點擊按鈕直接在本機彈出該資料夾。

### 2. ☁️ 雲端全功能模式 (推薦：GitHub 連接 Vercel，全自動抓取附檔)
- 將本專案上傳至 GitHub，並在 [Vercel](https://vercel.com/) 點擊 **Add New Project** 匯入本倉庫。
- **免設定任何參數，Vercel 原生支援 Python 雲端伺服器**！
- 手機、平板、任何筆電開啟專屬網址，上傳截圖後，**雲端伺服器會自動前往臺南教育局抓取所有官方附件（PDF、DOCX 等），自動打包成 ZIP 供您直接下載**！

### 3. 🌐 GitHub Pages 純靜態模式
- 適合僅需透過 GitHub Pages 免安裝辨識與備查截圖。
- 辨識後提供**「一鍵直連官方公告頁面」**，讓您在手機/筆電瀏覽器直接點選官方附檔下載。

---

## ⚠️ 常見疑問：為什麼有些公告沒有下載附檔？

1. **公告本身為「純文字公文」無附件**：
   - 例如範例公告 **`290612`**（請各校協助配合校內資訊組長115學年度每週五下午不排課務為原則）：
   - 經查臺南市教育局官方系統規則為「教育人員 瀏覽 O、**下載 X**」，該公告**本來就沒有夾帶任何附檔**。
2. **含有附檔之公告**：
   - 例如公告 **`293838`**（本土語競賽成績公布表）：官方有提供 2 份 PDF 成績單。在「本機模式」或「Vercel 雲端模式」下，系統均會**自動將 2 份 PDF 完整下載歸檔**！

---

## 🚀 3 步驟開啟雲端全功能移動辦公 (Vercel + GitHub)

1. 將本資料夾檔案上傳至您的 **GitHub Repository**。
2. 登入 [Vercel](https://vercel.com/)（可直接以 GitHub 帳號登入）。
3. 點擊 **Add New** ➔ **Project** ➔ 選取您的 GitHub 倉庫 ➔ 點擊 **Deploy**。
4. 部署完成後，即可獲得永久免費的雲端網址（例如 `https://tainan-bulletin.vercel.app`），在任何裝置都能完整下載官方附件！
